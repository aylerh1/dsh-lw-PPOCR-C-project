RESTful API 快速调用指南 (API Documentation)

POST /api/v1/ocr/recognitions

外部服务或智能体可通过标准 HTTP POST 请求调用本容器进行图像极速识别与多模态版面路由深度解析：

# 1. 深度多模态文档解析 (PP-DocLayout-S + SLANet 表格 + LaTeX 公式 + Markdown 重构)
curl.exe -X POST http://localhost:3000/api/v1/document \
  -H "Content-Type: application/json" \
  -d '{"file_path": "/app/test/fixtures/sample.png"}'

# 2. 单页版面分析路由 (快速输出区域类型 Title, Text, Table, Formula 及坐标)
curl.exe -X POST http://localhost:3000/api/v1/layout \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,..."}'

# 3. 极速纯文本 OCR (原生 C11 / AVX2，15~30ms 极速响应)
curl.exe -X POST http://localhost:3000/api/v1/ocr \
  -H "Content-Type: application/json" \
  -d '{"file_path": "/app/test/fixtures/sample.png"}'
